# Spazio — Prototipo

Prototipo standalone del gestionale per la gestione di una planimetria.

## Avvio

Aprire `index.html` direttamente nel browser. Non sono necessarie installazioni o connessioni internet.

## Funzioni incluse

- stanza con dimensioni in metri
- griglia e snap a 50 cm
- inserimento di colonne, mobili, scale e pareti interne
- inserimento di spazi espositivi
- inserimento di tavoli all'interno degli spazi
- drag & drop
- ridimensionamento tramite maniglia
- pannello proprietà
- nome commerciante
- colore espositore
- conteggio elementi e superficie tavoli per espositore
- zoom e adattamento alla vista
- undo/redo
- import JSON
- export JSON
- responsive layout di base

## Modello dati

Le coordinate e le dimensioni sono espresse in metri. Le coordinate dei tavoli sono relative al rispettivo espositore.

Il file JSON è il documento completo del progetto.
